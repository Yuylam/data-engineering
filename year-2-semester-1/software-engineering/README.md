## Course content
- Software Engineering
- Software Process Model
- Agile Software Development
- Requirements Engineering
- Requirement Analysis and Modeling
- Architectural Design
- Object-oriented Detailed Design
- Software Verification, Validation and Testing

## Assignments
### [Academic Writing: Past, Current and Future Trend in System Software Methodology]()
This paper discuss the past trends including the utilisation of monolith architecture and waterfall development model, the present trends including the agile methodology and user centric design, and the future trends including the AI integration and increased focus on security in system development.

## Project
The project in this subject continues the project from the subject [System Analysis and Design](/../year-1-semester-2/system-analysis-and-design/) of the previous semester. Combined with [Database](/database/) and [System Development Technology](/system-development-technology/), the complete system is developed.

This course supports the development process and documentations.

### [Project Proposal](/year-2-semester-1/software-engineering/project-proposal.pdf)
This document briefly disclose the goal and scope of the project, and the chosen software process model, which is the waterfall model.

### System Requirements Specification (SRS)
Two versions of SRS is documented according to different template and requirements required.

The [SRS document](/year-2-semester-1/software-engineering/project-srs.pdf) presents the system features with a descriptive manner, while the [SRS Agile document](/year-2-semester-1/software-engineering/project-srs-agile.pdf) presents the system features with User Stories.

### [System Design Document (SDD)](/year-2-semester-1/software-engineering/project-sdd.pdf)
This document documents the design of the system which would be used as reference in the development phase. More details of the architecture design, the database design and the interface design are included in the document.

### [System Testing Document (STD)](/database/project-phase3-logical-database-design.pdf)
This document was documented after the system is developed, with the details updated with the actual implementation. The system was tested with the test cases and the results were recorded.

## Reflection
This course guides us to build a develop a system step by step. From the documentation of requirement gathering to designing and to final testing.

## Assignments
### [Assignment 1 Blockchain for Supply Chain Transparency and Trust in Enterprise Systems](/assignment1-academic-writing.pdf)
Academic paper on the use of blockchain in enterprise supply chain systems.
- Studied blockchain architecture and enterprise integration
- Analysed transparency and trust in distributed systems
- Evaluated real-world applications in supply chain
- Discussed limitations such as scalability and oracle problem

### [Assignment 2 Industry Talk from PPG on SAP CoE Operations](/assignment2-industry-talk-sap-coe-operations.pdf)
Summary and reflection of an industry talk by PPG on SAP ERP evolution and operations.
- Learned SAP evolution from R/2 → R/3 → ECC → S/4HANA
- Understood ERP integration across global business processes
- Explored challenges in system migration and cloud adoption
- Reflected on enterprise system modernization

### [Assignment 3 UTHM Industial Visit](/assignment3-uthm-industrial-visit.pdf)
Report on UTHM data center and enterprise architecture initiative.
- Observed university digital infrastructure and data center design
- Learned challenges in networking, security, and power management
- Studied early-stage Enterprise Architecture (EA) implementation
- Reflected on real-world ICT system constraints

### [Project UTHM Enterprise Architecture](/project-report.pdf)
Designed an Enterprise Architecture model for UTHM as part of a class-wide integration project.
- Designed EA module using enterprise architecture principles
- Collaborated with class to integrate modules into full EA system
- Developed ERP prototype using Figma
- Studied SAP conceptual applications (not implemented in system)

## Reflection
Through this course, I learned how enterprise systems are used to integrate business processes into a unified system that enables efficient data sharing across departments and improves organisational workflow.

It was valuable to work on an enterprise architecture design for a university-based case study, as it provided practical insight into real-world system planning and integration.

SAP Build Apps was also explored during the course, although it was not used in the final project implementation. Nevertheless, it provided useful exposure to low-code enterprise application development tools.

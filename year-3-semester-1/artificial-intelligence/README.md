## Assignments
### [Project Proposal](/year-3-semester-1/artificial-intelligence/project-proposal.pdf)
This assignment applies the Design Thinking approach to address the challenges Mandarin learners face in remembering and writing Chinese characters correctly. Through the Empathise and Define stages, user needs, frustrations, motivations and learning preferences were identified using an empathy map and problem analysis, highlighting issues such as poor character retention, difficulty with stroke order and lack of engagement in traditional learning methods. The proposed AI solution, Rydit: Learn Mandarin, combines handwriting recognition, adaptive learning, spaced repetition and gamification to provide personalised feedback, improve character retention and create a more engaging Mandarin learning experience.

### [Final Report](/year-3-semester-1/artificial-intelligence/project-final-report.pdf)
In the project, the design of Rydit: Learn Mandarin was developed, by applying core Artificial Intelligence concepts such as knowledge representation, model-based reflex agents, adaptive feedback systems and state space search. The project demonstrated how AI can analyse user handwriting, represent learning progress through logical rules and predicates, and make intelligent decisions regarding character revision, feedback delivery and lesson progression. Through the integration of handwriting recognition, personalised learning, spaced repetition and reward mechanisms, the system showcases how AI techniques can be used to improve Mandarin writing accuracy, long-term retention and learner engagement.

## Reflection
This course was not what I imagined it would be. Instead of learning intricate AI algorithms, we explored the fundamentals of AI, including knowledge representation and the logical reasoning that drives intelligent systems. Although it is still amazing to think that these basic concepts come together to create the powerful AI models we see and use today, the course has given me a strong foundation in the core theories behind Artificial Intelligence.

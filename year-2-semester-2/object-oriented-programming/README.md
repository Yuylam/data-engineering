## Project
### [Console-based Online Shopping Cart System](/year-2-semester-2/object-oriented-programming/project/)
This project is a console-based online shopping cart system built in Java. It supports: 
* Customers browse and add items to the shopping cart 
* Administrators manage items and view/update customer orders (shopping cart) 
The system uses object-oriented design principles to simulate e-commerce scenarios, and applies  Java's  collection  framework  and  exception  handling  to  enhance  functionality  and stability.

## Assignments
### [Lab Assignment 1 Basic Concepts and Tools Related to Operating System](/year-2-semester-2/operating-systems/lab-assessment01.pdf)
This operating systems lab assessment provides hands-on practice with basic Linux commands, file and text manipulation, and C programming using tools such as echo, cat, nano, and gcc. 

### [Lab Assignment 2 Process monitoring and management in operating system](/year-2-semester-2/operating-systems/lab-assessment02.pdf)
This laboratory assessment enabled me to develop practical skills in Linux process monitoring and management using commands such as ps, pstree, renice and killall. Additionally, process creation, hierarchy, scheduling, and synchronisation concepts were demonstrated through the implementation and execution of a multiprocessing program.

### [Lab Assignment 3 File Management](/year-2-semester-2/operating-systems/lab-assessment03.pdf)
In this laboratory exercise, file management tasks were successfully performed using Bash scripting to create and organise directories, files, and directory structures. Additionally, file permissions and access controls were configured and modified, enhancing understanding of Linux file system management and security.

### [Project Virtual Memory Management – Replacement Algorithm: FIFO, LRU](/year-2-semester-2/operating-systems/project-report.pdf)
In this project, FIFO and LRU page replacement algorithms were implemented and evaluated using a fixed reference string and three memory frames. The simulation results showed that LRU produced fewer page faults (12) than FIFO (15), indicating better memory management performance. Overall, the project enhanced understanding of virtual memory concepts and the practical application of page replacement algorithms in operating systems.

## Assignments
### [Assignment 1](/year-2-semester-2/data-analytics-programming/assignment1.ipynb)
In this assignment, ride-sharing data were successfully processed using Python through the application of file handling, data structures, functions and lambda expressions. The dataset was analysed to generate city-based fare statistics, driver performance summaries and ride insights from selected data slices.

### [Assignment 2](/year-2-semester-2/data-analytics-programming/assignment2.ipynb)
In this assignment, retail sales data were analysed using Pandas DataFrames and MultiIndexing techniques. Various data manipulation tasks, including sorting, filtering, grouping, aggregation, normalisation, and hierarchical indexing, were successfully performed to extract meaningful business insights.

### [Assignment 3](/year-2-semester-2/data-analytics-programming/assignment2.ipynb)
In this assignment, rainfall data were successfully analyzed using Python through data cleaning, aggregation, and visualisation techniques with Pandas, NumPy, Matplotlib and Seaborn. The analysis explored rainfall patterns across regions, stations, and time periods, revealing key trends through statistical summaries, grouped computations and multiple visual representations.

### [Project](/year-2-semester-2/data-analytics-programming/project.ipynb)
This project integrates and cleans car registration and fuel consumption datasets, then performs exploratory analysis, aggregation, and visualisation to understand emissions and fuel efficiency patterns. Machine learning methods (KMeans clustering and Random Forest classification) are used to group vehicles by emission behaviour and predict emission categories based on engine size and fuel consumption features. Overall, the results show that fuel consumption and engine size are strong indicators of CO₂ emissions, enabling effective classification of vehicle environmental impact.

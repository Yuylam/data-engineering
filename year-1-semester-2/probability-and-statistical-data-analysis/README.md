- Chi-Square Test
- Contigency Analysis
- Correlation
- Regression

## Reflection
We'll always make guesses and make reasoning or inference with what we think it should be, but the truth is, it may be not correct. We should have supporting data and proof that our "hypothesis" is statistically correct.

# Computer Organisation and Architecture
In this course, we are going to learn C++ programming language and develop programs to solve simple or moderate problems.

- [Course content](#course-content)
- [Assignments](#assignments)
- [Reflection](#reflection)

## Course content
- Basic Concepts of Computer
- Data Representation in Computer Systems
- Introduction to Assembly Language Programming
- Instruction Set Architecture (ISA)
- Central Processing Unit (CPU)
- Memory Systems
- Input/Output (I/O) and Storage System
- Performance Measurements and Analysis

## Lab
- The labs are a series of Assembly Language Programming exercises.

### [Lab 1: Assembly Language Fundamentals](/computer-organisation-and-architecture/Lab%201%20Assembly%20Language%20Fundamentals.pdf)
- Dealt with simple add and subtract and learning about the debugging procees.
- [Lab 1a](/computer-organisation-and-architecture/lab%201a%20Add%20and%20Subtract%20v1.asm) is a program that adds and subtracts 32-bit integers.
- [Lab 1b](/computer-organisation-and-architecture/lab%201b%20Add%20and%20Subtract%20v2.asm) is a program that adds and subtracts 32-bit unsigned integers and stores the sum in a variable.
- [Lab 1c](/computer-organisation-and-architecture/lab%201c%20Add%20and%20Subtract%20v3.asm) is a program that adds and subtracts 8 and 16 bit unsigned integers and stores the sum in a vaiable.

### [Lab 2: Arithmetic Equations & Operations](/computer-organisation-and-architecture/Lab%202%20Arithmetic%20Equations%20and%20Operations.pdf)
- Inspected the program line by line and the content of the related registers.

### [Lab 3: Interactive Usage of Link Libraries & Comparison and Conditional Jumps](/computer-organisation-and-architecture/Lab%203%20Interactive%20Usage%20of%20Link%20Libraties%20and%20Comparison%20&%20Conditional%20Jumps.pdf)
- Learned some other Library Procedures other than DumpRegs that are used in previous Lab.
- Implemented program using LOOP and AND
- [Lab 3.1c Program 1](/computer-organisation-and-architecture/lab%203.1c%20Program%201%20LOOP%20and%20ADD.asm) is a program that calculates the perimeter of 2 hexagons according to keyboard inputs
- [Lab 3.1c Program 2](/computer-organisation-and-architecture/lab%203.1c%20Program%202.asm) is a program that sum the numbers in even and odd index separately
- [Lab 3.2c](/computer-organisation-and-architecture/lab%203.2c%20Simple%20Menu.asm) combines the two programs above and create a menu for the user to select which operation to execute.


## [Group Project](/computer-organisation-and-architecture/Project%20Report.pdf)
- Conducted benchmarking and performance comparison and analysis to our computers
- Tools: CPU-Z, Geekbench, Windows Task Manager, MiniTool Partition Wizard
- An [assembly code](/computer-organisation-and-architecture/project.asm) is also written to perform stress test and compare the execution time between computers.

## Reflection
Its cool to learn about the computer into the "unseen" parts of it, including the representation of data, how the memory "looks like" in a conceptual manner, how memory access happens and how we can check if the data stored is corrupted. Although the understanding is more towards conceptual, it brings us back to how the computer stores the 0s and 1s. The assembly language is another part that makes me wonder, since our labs are only simple and short programs, how would it look like when the high-level programming languages translate to assembly language. There are so much more to explore.

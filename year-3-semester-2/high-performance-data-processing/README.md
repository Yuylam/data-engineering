# High Performance Data Processing
This course covers the fundamentals of high- performance computing, data processing, and high-performance data processing architecture. Students will also be exposed to case studies in industry and research that make use of high-performance data processing. Students will gain hands-on experience with Amazon Web Services (AWS) as a data processing platform.

## Assignments
### [Assignment: Academic Writing](/year-3-semester-2/high-performance-data-processing/assignment-academic-writing.pdf)
In this assignment, a comparative analysis was conducted on three document-oreinted database, namely MongoDB, CouchDB, and Firebase Firestore. These NoSQL databases were compared upon their data model, query mechanism, consistency, replication, scalabily and respective suitable use-case. Despite all being document-oriented database, each have different strength and weaknesses, and the choice of database should depend on the need and situation.

### [Project 1 Maukerja Job Scraping and Data Processing Benchmark](https://github.com/drshahizan/HPDP/tree/main/2526/project/p1/TripleA)
In this this project, data was first scraped from Maukerja website, processed, and the data was then used to benchmark three data processing libraries including pandas, polars, and Spark.

This project was meaningful as it involved collecting real-world data rather than using a benchmark dataset. The most interesting part was the web scraping process, where most of the challenges were encountered. As the dataset grew, processing time increased and the workflow became slower, which was addressed by improving data handling through deduplication, chunking, and periodic saving.
